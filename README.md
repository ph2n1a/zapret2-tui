# zapret2-tui

## About the program
This is a C program primarily for Linux systems and Linux routers (Entware and OpenWRT). This program is not a separate version of zapret2, but rather an add-on.

## The essence of the program
The program greatly simplifies working with zapret2 while still allowing the same freedom of action. The basic concept is to split all strategies into profiles for quick switching. Each profile corresponds to its own strategy, and the profiles themselves must be created manually through the profiles.conf configuration file; all formatting rules are specified in the configuration file itself. For convenience, the program also allows you to view the status of the zapret2 service and perform actions on it (start, stop, restart).
